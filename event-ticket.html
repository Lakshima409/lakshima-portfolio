Event Ticket Online Web Application

Overview

A scalable, full-stack event ticket booking platform with secure payment integration, role-based access control, and comprehensive event management features. Facilitates end-to-end event ticketing from organizer setup through attendee booking to post-event analytics.

Project type

Solo build · ASP.NET MVC full-stack · 2025

My Role

Full-stack development across the entire booking journey: event catalog, booking flow, secure checkout, and organizer analytics. Owned booking history, favorites, and digital-wallet features end to end.

Key outcomes

  • End-to-end checkout with payment protection
  • QR-code e-tickets with real-time validation & overbooking prevention
  • Organizer dashboard with sales analytics and attendance tracking

Architecture & Design

  • Framework: ASP.NET MVC with clean architectural principles
  • High cohesion: logically organized service layers
  • Security: role-based access, payment data protection

Core Features

  • Event creation, venue setup, ticket tiers
  • Booking with seat selection and live price summary
  • QR-code e-tickets with validation
  • Payment integration, analytics dashboard
