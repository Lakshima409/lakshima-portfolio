Luxora Hotel Suite – Property Management System

Overview

A comprehensive full-stack web-based hotel reservation and property management system built collaboratively with a 4-person Agile team. The system handles end-to-end hotel operations from online reservations through to guest check-out and billing in a single workflow.

Project type

Agile team project · Full-Stack · PHP 8+, MySQL, Bootstrap · 2025–2026

My Role

Full-Stack Developer owned the billing engine and the check-in/check-out modules. Responsible for dynamic invoicing, split payments, late-checkout penalty rules, and no-show detection, plus the real-time occupancy & revenue admin screens.

Key outcomes

  • Dynamic invoicing and split payments across rooms/rooms-services
  • Late-checkout penalty + no-show detection with automated enforcement
  • Role-based admin dashboards with audit logging

Project Screenshots

Live captures from the running Luxora Hotel Suite system (localhost), including the authenticated admin dashboard.

Architecture

Layered architecture with a PHP 8+ RESTful backend, MySQL InnoDB storage, and a Bootstrap 5 frontend. Role-based access separates admin, clerk, and guest journeys into independent routes and controllers.

Challenges & Improvements

  • Multi-role UX coordinated booking, billing, check-in and reporting across three user roles; solved with role-based route guards and a shared dashboard shell.
  • Payment handling no live gateway; encoded fallback to simulated split payments and manual reconciliation runs.
  • Refinements extend reporting with a booking-prepaid dashboard, mobile-responsive clerk workflows, and CI with automated schema migrations.
