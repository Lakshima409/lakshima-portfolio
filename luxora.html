Luxora Hotel Suite – Property Management System

Project Overview

A comprehensive full-stack web-based hotel reservation and property management system built collaboratively with a 4-person Agile team. The system handles end-to-end hotel operations from online reservations through to guest check-out and billing.

Role & Responsibilities

Full-Stack Developer responsible for designing and implementing the billing engine and check-in/check-out modules, with emphasis on dynamic invoicing, split payments, and flexible reservation handling.

Technology Stack

  • Frontend: HTML5, Bootstrap 5, responsive design
  • Backend: PHP 8+, RESTful API design
  • Database: MySQL with InnoDB storage engine, database normalization
  • Security: Role-based access control, audit logging, secure payment handling

Key Features Implemented

  • Integrated reservation system with dynamic pricing
  • Tax calculations and automated rule enforcement
  • Late-checkout penalty system and no-show detection
  • Split payment processing and flexible invoicing
  • Role-based administration dashboards
  • Comprehensive audit logging and compliance tracking

Skills Demonstrated

Full-Stack Web Development · PHP 8+ · MySQL Database Design · Agile Teamwork · Payment Integration · Business Logic Implementation
