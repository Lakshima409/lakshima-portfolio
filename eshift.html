eShift – Household Goods Transport Management System

Overview

A desktop transport management system automating operations for a household goods transportation company. End-to-end flow from booking and dispatch through delivery, payment, and reporting.

Project type

Solo build · C# Windows Forms + SQL Server · 2025

My Role

Owned auth, bookings, and the SQL design. Role-based login with BCrypt, six forms, PDF/Excel reporting, and a job-request workflow.

Key outcomes

  • BCrypt role-based login (admin/customer)
  • Six forms across booking, fleet, vehicles, and reports
  • PDF and Excel export; manual entry cut from ~15 min to ~2 min per job

Architecture

Layered architecture with clear separation of concerns: C# Windows Forms client, SQL Server storage, and a dedicated reporting service. BCrypt-encrypted credentials gate admin and customer role paths.

Challenges & Improvements

  • Data integrity – validated against representative booking datasets and manual spot-checks.
  • Refinements – move to web deployment, add role-based dashboards, and expand reporting exports.

Skills Demonstrated

C# Windows Forms · SQL Server · Desktop Application Development · Business Logic Implementation · Database Normalization · Security & Encryption
