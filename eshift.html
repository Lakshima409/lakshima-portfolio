eShift – Household Goods Transport Management System

Project Overview

A desktop-based transport management system designed to automate and streamline operations for a household goods transportation company. The system handles end-to-end transport logistics from booking through to delivery and payment.

Key Features

  • Role-based Authentication: Secure user access with differentiated permissions for operators, drivers, and administrators
  • Transport Booking: Customer request management, quote generation, and booking confirmation
  • Vehicle & Driver Management: Fleet tracking, driver allocation, and vehicle maintenance scheduling
  • Route Optimization: Efficient route planning and delivery tracking
  • Reporting: PDF and Excel export for performance analytics and compliance

Technology Stack

  • Platform: C# Windows Forms desktop application
  • Database: SQL Server with advanced querying
  • Security: BCrypt password encryption, role-based access control
  • Architecture: Layered architecture with clear separation of concerns

Development Practices

  • Object-Oriented Programming principles and design patterns
  • Database normalization and optimization
  • Comprehensive system and unit testing
  • Secure credential storage and encryption

Skills Demonstrated

C# Windows Forms · SQL Server · Desktop Application Development · Business Logic Implementation · Database Normalization · Security & Encryption
