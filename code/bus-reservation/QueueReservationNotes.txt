Let's implement a reservation system for the bus reservation system using a queue data structure. In this setup, a queue is used to manage the reservation requests in a first-in, first-out (FIFO) manner. When a customer reserves a seat, it's akin to enqueueing, while cancellation is akin to dequeueing. Let's create a Java implementation that includes these features.

Java Code Implementation with Queue for Reservation System
java
Copy code
import java.util.*;

class Customer {
    String name;
    String mobile;
    String email;
    String city;
    int age;

    public Customer(String name, String mobile, String email, String city, int age) {
        this.name = name;
        this.mobile = mobile;
        this.email = email;
        this.city = city;
        this.age = age;
    }

    @Override
    public String toString() {
        return name + " (" + age + ")";
    }
}

class Bus {
    String busNumber;
    int totalSeats;
    int reservedSeats = 0;
    String startingPoint;
    String endingPoint;
    String startingTime;
    double fare;

    public Bus(String busNumber, int totalSeats, String startingPoint, String endingPoint, String startingTime, double fare) {
        this.busNumber = busNumber;
        this.totalSeats = totalSeats;
        this.startingPoint = startingPoint;
        this.endingPoint = endingPoint;
        this.startingTime = startingTime;
        this.fare = fare;
    }

    public boolean hasAvailableSeats() {
        return reservedSeats < totalSeats;
    }

    public void reserveSeat() {
        if (hasAvailableSeats()) {
            reservedSeats++;
        }
    }

    public void cancelReservation() {
        if (reservedSeats > 0) {
            reservedSeats--;
        }
    }

    @Override
    public String toString() {
        return busNumber + ": " + startingPoint + " to " + endingPoint + ", Starts at " + startingTime + ", Fare: " + fare;
    }
}

class Reservation {
    Customer customer;
    Bus bus;

    public Reservation(Customer customer, Bus bus) {
        this.customer = customer;
        this.bus = bus;
    }

    @Override
    public String toString() {
        return "Reservation for " + customer.name + " on bus " + bus.busNumber;
    }
}

public class BusReservationSystem {
    private List<Customer> customers = new LinkedList<>();
    private List<Bus> buses = new LinkedList<>();
    private Queue<Reservation> reservations = new LinkedList<>();

    public void registerCustomer(String name, String mobile, String email, String city, int age) {
        Customer newCustomer = new Customer(name, mobile, email, city, age);
        customers.add(newCustomer);
        System.out.println("Registered customer: " + newCustomer);
    }

    public void registerBus(String busNumber, int totalSeats, String startingPoint, String endingPoint, StartingTime, Fare) {
        Bus newBus = new Bus(busNumber, totalSeats, startingPoint, endingPoint, StartingTime, Fare);
        buses.add(newBus);
        System.out.println("Registered bus: " + newBus);
    }

    public void reserveSeat(String customerName, String busNumber) {
        Customer customer = customers.stream().filter(c -> c.name.equals(customerName)).findFirst().orElse(null);
        Bus bus = buses.stream().filter(b -> b.busNumber.equals(busNumber)).findFirst().orElse(null);

        if (customer != null && bus != null && bus.hasAvailableSeats()) {
            bus.reserveSeat();
            Reservation reservation = new Reservation(customer, bus);
            reservations.add(reservation);
            System.out.println("Seat reserved for " + customer.name + " on bus " + bus.busNumber);
        } else {
            System.out.println("Unable to reserve seat.");
        }
    }

    public void cancelReservation() {
        Reservation canceledReservation = reservations.poll();
        if (canceledReservation != null) {
            Bus bus = canceledReservation.bus;
            bus.cancelReservation();
            System.out.println("Reservation canceled for " + canceledReservation.customer.name + " on bus " + bus.busNumber);
        } else {
            System.out.println("No reservations to cancel.");
        }
    }

    public void displayReservations() {
        System.out.println("Current reservations:");
        for (Reservation reservation : reservations) {
            System.out.println(reservation);
        }
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        BusReservationSystem system = new BusReservationSystem();
        
        // Customer registration
        System.out.println("Registering customers...");
        system.registerCustomer("Alice", "1234567890", "alice@example.com", "New York", 30);
        system.registerCustomer("Bob", "0987654321", "bob@example.com", "Los Angeles", 25);
        
        // Bus registration
        System.out.println("Registering buses...");
        system.registerBus("B001", 40, "New York", "Los Angeles", "08:00 AM", 50.0);
        system.registerBus("B002", 50, "Los Angeles", "New York", "09:00 AM", 55.0);

        // Reserve seats
        System.out.println("Reserving seats...");
        system.reserveSeat("Alice", "B001");
        system.reserveSeat("Bob", "B001");

        // Display reservations
        system.displayReservations();

        // Cancel a reservation
        System.out.println("Canceling a reservation...");
        system.cancelReservation();

        // Display reservations after cancellation
        system.displayReservations();
    }
}
Explanation
Queue: The reservations field is a queue that represents a list of reservation requests in the order they were made.
Reservation System: The reserveSeat method checks if a given customer and bus exist and whether there are available seats. If all conditions are met, a new reservation is created, the seat is reserved, and the reservation is added to the queue. The customer receives a message confirming the reservation.
Cancel Reservation: The cancelReservation method uses poll() to remove the front of the queue, representing a canceled reservation. The bus reservation count is updated, and a message is printed to notify the customer of the cancellation.
Display Reservations: This method iterates through the queue and displays the current list of reservations.
Main Method: In the main method, the system registers customers and buses, reserves seats, displays reservations, cancels a reservation, and then displays the updated reservations list.
