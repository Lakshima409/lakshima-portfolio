Algorithm 1: QuickSort
QuickSort is a highly efficient sorting algorithm that follows the "divide and conquer" principle. As the author, I chose QuickSort for its average-case time complexity of O(n log n) and its adaptability to various data sets.

How QuickSort Works: QuickSort selects a 'pivot' element from the data set and partitions the rest of the elements into two groups: those less than or equal to the pivot and those greater than the pivot. It then recursively applies the same process to the two partitions until they are sorted. Once each partition is sorted, QuickSort combines them to create a sorted array.
Advantages of QuickSort: QuickSort is generally faster than other comparison-based sorting algorithms, making it suitable for large data sets like customer databases in a bus reservation system. It requires relatively low additional memory, offering an in-place sorting capability. This characteristic is essential in systems where memory constraints are a concern.
Considerations: QuickSort's worst-case time complexity is O(n^2), which occurs when the pivot selection is poor (e.g., if the array is already sorted). However, with random pivot selection or specific pivot strategies, this worst-case scenario can be mitigated. Given its efficiency, QuickSort is a reliable choice for sorting customer data by age, allowing for quick retrieval and processing.
Algorithm 2: MergeSort
MergeSort is another efficient sorting algorithm with a consistent time complexity of O(n log n), making it a robust alternative to QuickSort. As the author, I chose MergeSort for its stability and ability to handle large data sets without degrading in performance.

How MergeSort Works: MergeSort divides the data set into smaller halves recursively until each segment contains a single element. Then, it merges these segments in order, creating a sorted array. This merge process continues until the entire data set is sorted.
Advantages of MergeSort: MergeSort is a stable sorting algorithm, meaning that equal elements retain their relative order in the sorted output. This property is crucial when sorting complex objects, like customer records with multiple attributes. MergeSort's consistent time complexity of O(n log n) makes it reliable for large-scale sorting operations.
Considerations: MergeSort requires additional memory for the merging process, typically O(n), making it less memory-efficient than QuickSort. However, this overhead is manageable in modern systems, especially when stability and consistent performance are prioritized.

As the author, I believe both QuickSort and MergeSort offer compelling advantages for sorting the customer base by age in a bus reservation system. class QuickSort {
    public void quickSort(Customer[] customers, int low, int high) {
        if (low < high) {
            int pi = partition(customers, low, high);
            quickSort(customers, low, pi - 1);
            quickSort(customers, pi + 1, high);
        }
    }

    private int partition(Customer[] customers, int low, int high) {
        Customer pivot = customers[high];
        int i = (low - 1);
        
        for (int j = low; j < high; j++) {
            if (customers[j].age <= pivot.age) {
                i++;
                swap(customers, i, j);
            }
        }

        swap(customers, i + 1, high);
        return (i + 1);
    }

    private void swap(Customer[] customers, int i, int j) {
        Customer temp = customers[i];
        customers[i] = customers[j];
        customers[j] = temp;
    }
}

class MergeSort {
    public void mergeSort(Customer[] customers, int left, int right) {
        if (left < right) {
            int mid = left + (right - left) / 2;

            mergeSort(customers, left, mid);
            mergeSort(customers, mid + 1, right);

            merge(customers, left, mid, right);
        }
    }

    private void merge(Customer[] customers, int left, int mid, int right) {
        int n1 = mid - left + 1;
        int n2 = right - mid;

        Customer[] leftArray = new Customer[n1];
        Customer[] rightArray = new Customer[n2];

        System.arraycopy(customers, left, leftArray, 0, n1);
        System.arraycopy(customers, mid + 1, rightArray, 0, n2);

        int i = 0, j = 0;
        int k = left;

        while (i < n1 && j < n2) {
            if (leftArray[i].age <= rightArray[j].age) {
                customers[k] = leftArray[i];
                i++;
            } else {
                customers[k] = rightArray[j];
                j++;
            }
            k++;
        }

            i++;
            k++;
        }

class MergeSort {
    public void mergeSort(Customer[] customers, int left, int right) {
        if (left < right) {
            int mid = left + (right - left) / 2;

            mergeSort(customers, left, mid);
            mergeSort(customers, mid + 1, right);

            merge(customers, left, mid, right);
        }
    }

    private void merge(Customer[] customers, int left, int mid, int right) {
        int n1 = mid - left + 1;
        int n2 = right - mid;

        Customer[] leftArray = new Customer[n1];
        Customer[] rightArray = new Customer[n2];

        System.arraycopy(customers, left, leftArray, 0, n1);
        System.arraycopy(customers, mid + 1, rightArray, 0, n2);

        int i = 0, j = 0;
        int k = left;

        while (i < n1 && j < n2) {
            if (leftArray[i].age <= rightArray[j].age) {
                customers[k] = leftArray[i];
                i++;
            } else {
                customers[k] = rightArray[j];
                j++;
            }
            k++;
        }

        while (i < n1) {
            customers[k] = leftArray[i];
            i++;
            k++;
        }

        while (j < n2) {
            customers[k] = rightArray[j];
            j++;
            k++;
        }
    }
}
