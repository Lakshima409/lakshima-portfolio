Java Implementation of Bus Reservation System
To implement a bus reservation system in Java, you'd need classes to represent customers, buses, and reservations. Here's an example implementation for customer and bus registration, using arrays and linked lists.

java
Copy code
import java.util.*;

class Customer {
    String name;
    String mobile;
    String email;
    String city;
    int age;

    public Customer(String name, String mobile, String email, String city, int age) {
        this.name = name;
        this.mobile = mobile;
        this.email = email;
        this.city = city;
        this.age = age;
    }

    @Override
    public String toString() {
        return name + " (" + age + ")";
    }
}

class Bus {
    String busNumber;
    int totalSeats;
    String startingPoint;
    String endingPoint;
    String startingTime;
    double fare;

    public Bus(String busNumber, int totalSeats, String startingPoint, String endingPoint, String startingTime, double fare) {
        this.busNumber = busNumber;
        this.totalSeats = totalSeats;
        this.startingPoint = startingPoint;
        this.endingPoint = endingPoint;
        this.startingTime = startingTime;
        this.fare = fare;
    }

    @Override
    public String toString() {
        return busNumber + ": " + startingPoint + " to " + endingPoint + ", Starts at " + startingTime + ", Fare: " + fare;
    }
}

public class BusReservationSystem {
    private List<Customer> customers = new LinkedList<>();
    private List<Bus> buses = new LinkedList<>();
    private Map<String, Stack<String>> reservationHistory = new HashMap<>();

    public void registerCustomer(String name, String mobile, String email, String city, int age) {
        Customer newCustomer = new Customer(name, mobile, email, city, age);
        customers.add(newCustomer);
    }

    public void registerBus(String busNumber, int totalSeats, String startingPoint, String endingPoint, String startingTime, double fare) {
        Bus newBus = new Bus(busNumber, totalSeats, startingPoint, endingPoint, startingTime, fare);
        buses.add(newBus);
    }

    public void printCustomers() {
        System.out.println("Registered Customers:");
        for (Customer c : customers) {
            System.out.println(c);
        }
    }

    public void printBuses() {
        System.out.println("Registered Buses:");
        for (Bus b : buses) {
            System.out.println(b);
        }
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        BusReservationSystem system = new BusReservationSystem();
        
        // Customer registration
        System.out.println("Registering customers...");
        system.registerCustomer("Alice", "1234567890", "alice@example.com", "New York", 30);
        system.registerCustomer("Bob", "0987654321", "bob@example.com", "Los Angeles", 25);
        
        // Bus registration
        System.out.println("Registering buses...");
        system.registerBus("B001", 40, "New York", "Los Angeles", "08:00 AM", 50.0);
        system.registerBus("B002", 50, "Los Angeles", "New York", "09:00 AM", 55.0);

        // Display registered customers and buses
        system.printCustomers();
        system.printBuses();
    }
}
In this code, I created classes for Customer and Bus, with methods to register customers and buses. The BusReservationSystem class manages these registrations using linked lists for easy insertion and deletion. A Stack is used to maintain a history of reservations. Error handling can be added to manage invalid inputs or out-of-range operations.
